**Madison Parker**

Module Six is where the Angular admin side really came together. I used the REST API from the previous module and built the trip listing, add, edit, and delete workflow into the SPA.

## What I worked on

- Angular components and routing
- Reusable trip cards
- `TripDataService` for API calls
- Reactive forms for adding and editing trips
- CRUD operations from the admin site
- Testing the Angular frontend with the API

In `module7` I added the login and security layer so the write actions were only allowed after authentication.
