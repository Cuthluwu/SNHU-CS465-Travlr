Module Three is where I stopped hard-coding the trip cards directly into the page and started using structured trip data instead. The travel page could loop through JSON data with Handlebars, which made the page easier to update and prepared the project for the database work that came next.

## What I worked on

- JSON trip data
- Handlebars loops
- Dynamic trip rendering
- Separating the data from the page layout
- Cleaning up repeated markup

In `module4` I moved the trip data into MongoDB and added Mongoose models and database setup.
