## Checkpoint Focus

Module Four replaced temporary trip storage with a MongoDB database. Mongoose provided the model and schema layer, while the seed process made it possible to rebuild a predictable set of travel records for development and testing.

### Skills represented at this checkpoint

- MongoDB document persistence
- Mongoose schemas and models
- Database connection lifecycle
- Seed-data workflow
- Moving application data from local JSON toward a persistent backend
