**Madison Parker**

Module Four is where the project stopped relying on temporary trip data and started using MongoDB. I added the Mongoose model/schema setup and a seed process so I could rebuild the same trip records when testing.

## What I worked on

- MongoDB connection
- Mongoose schemas and models
- Trip data stored in the database
- Seed data for repeatable testing
- Connecting the server to MongoDB

In `module5` I built out the REST API so the application could request trip data through endpoints instead of reading it directly.
