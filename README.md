## Checkpoint Focus

Module Two reorganized the customer-facing Travlr site into a clearer Express MVC structure. Routes, controllers, Handlebars views, and reusable partials separated page behavior from presentation and reduced repeated markup.

### Skills represented at this checkpoint

- Express routing and controllers
- MVC separation of concerns
- Handlebars templates
- Reusable header/footer partials
- Refactoring static pages into server-rendered views
