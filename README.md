## Checkpoint Focus

Module Three moved the trip content away from repeated static markup and into structured JSON data. The customer-facing travel page could then iterate over trip records through Handlebars, making the page easier to maintain and preparing the application for database-backed data later in the course.

### Skills represented at this checkpoint

- JSON data structures
- Dynamic Handlebars iteration
- Separation of data from presentation
- Reusable rendering patterns
- Refactoring for maintainability
